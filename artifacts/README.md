# Offline artifacts

Place locally verified artifacts here; do not commit binaries.

- `node-v22.22.0-linux-x64.tar.gz` or `.tar.xz` — official Node.js archive
- a selected Ubuntu 22.04 `needrestart` `.deb` older than `3.5-5ubuntu2.2`

Record source URLs and SHA-256 values in the private repository or exercise build manifest before freezing the image.
